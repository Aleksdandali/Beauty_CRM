🔑 Получить API Ключ из Supabase

Шаг 1: Открой страницу настроек

Нажми на кнопку ниже - откроется нужная страница в Supabase:

Шаг 2: Прокрути вниз

На открывшейся странице прокрути вниз до секции Project API keys

Шаг 3: Найди ключ

Там будет таблица с ключами:

  • anon public - ВОТ ЭТОТ! ✅
  • service_role - НЕ этот! ❌

Шаг 4: Скопируй ключ

Нажми на иконку 📋 (копировать) рядом с anon public ключом.

Ключ начинается с eyJhbGc... и очень длинный.

Шаг 5: Вставь в терминал

Вернись в терминал и выполни команду:

echo 'NEXT_PUBLIC_SUPABASE_URL=https://hotglyzmwkowxxlnhros.supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY=ВСТАВЬ_СЮДА_КЛЮЧ' > /Users/oleksandr/beauty-crm/.env.local

Замени ВСТАВЬ_СЮДА_КЛЮЧ на скопированный ключ!

✅ Готово!
